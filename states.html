what you should have seen

  • Attractors (blue) pull nearby particles toward them. Left alone, the system settles into them.
  • Repellers (orange) push nearby particles away. The system doesn't want to stay in that state, because it is unstable like balancing a pencil on its tip.
  • Saddles (purple) pull particles along one axis and push them along the perpendicular axis. They're stable in one direction and unstable in the other like a mountain pass. Use select to rotate a saddle so its axes align however you like.

Drop particles near a mix of these and watch their behavior. Or hit scatter particles to fill the whole canvas and watch them flow. Select any node to adjust its strength (stronger nodes exert more force) so particles move faster around them.

NOTE: One function of this code is that it assumes we are looking at only one window of the system. This means that the system goes on forever in all directions and I depicted this by having particles that get pushed past the edge simply leave the map. No walls, no bouncing. Once the particle leaves this window we assume it goes into another map that we don't have imagined here.
